# Projects - MSc in Robotics and Mechatronics Engineering


Check out the website version: https://andreagalenda.github.io/Projects/


This repository contains the projects developed during my MSc in Robotics and Mechatronics Engineering at Politecnico di Milano. Each folder contains the comprehensive reports in PDF format alongside the associated simulation and analysis code where available (MATLAB, Python, C++).

Below is a detailed breakdown of the projects included in this repository.

### Highlighted Projects (Mechanisms, Robotics & Structural Simulation)

These projects are highly relevant to space mechanisms engineering, finite element analysis, multi-body dynamics, and advanced robotics.

*   **[Lab_Industrial_Robotics](./Lab_Industrial_Robotics/) - Mechanism Design and Robotics**
    *   **Focus:** Mechanism Design, Mechatronics, Actuation.
    *   **Description:** Designed and 3D printed a custom support and an electrically actuated end-effector to secure and manipulate the opening mechanism of a modular motorcycle helmet. Programmed robot path planning and motion in Python with autonomous task verification via camera and torque feedback.

*   **[Machine_Learning_for_Mechanical_Systems/SayCan](./Machine_Learning_for_Mechanical_Systems/SayCan_for_Pick_and_Place.pdf)**
    *   **Focus:** Advanced Robotics, Vision-Language Models, Task Planning.
    *   **Description:** Implemented a SayCan framework for a robotic arm to perform autonomous pick-and-place operations. Combined Large Language Models (LLMs) for semantic scoring with ViLD (Vision-Language Detection) and CLIPort for visual affordance scoring to enable complex, language-guided robotic manipulation tasks.

*   **[Advanced_Dynamics_For_Mechanical_System](./Advanced_Dynamics_For_Mechanical_System/) - Modal & Finite Element Analysis (FEA)**
    *   **Focus:** Finite Element Analysis, Structural Dynamics, Frequency Domain Analysis.
    *   **Description:** Performed Modal Analysis on a rail wheel using frequency domain data from impulse tests via least square error minimization. Conducted a comprehensive Finite Element Analysis on a harbor crane to reconstruct its modal parameters, mode shapes, and its static and dynamic responses under moving loads.

*   **[Data_Analysis_for_Mechanical_Systems](./Data_Analysis_for_Mechanical_Systems/) - Operational Modal Analysis (OMA)**
    *   **Focus:** Structural Health Assessment, Test Data Processing, System Identification.
    *   **Description:** Reconstructed the Modal Parameters and Frequency Response Functions of tie rods from natural excitation (NExT) data using the Frequency Domain Decomposition (FDD) algorithm. Isolated modal parameter variations due to structural damage from thermal and environmental disturbances.

### Additional Projects (Machine Learning & Advanced Simulation)

*   **[Model_Order_Reduction](./Model_Order_Reduction/) - Reduced Order Modeling for Complex Physics**
    *   **Focus:** Numerical Simulation, Linear Elasticity, Data-Driven Physics Modeling.
    *   **Description:** Developed Reduced Order Models (ROM) using POD-Galerkin and Singular Value Decomposition (SVD) for complex simulations. Contains two main assignments:
        *   **Playground Safety:** Modeled the deformation of a polyurethane foam playground floor under the weight of an ambulance using linear elasticity equations.
        *   **Stunt Training Facility:** Applied ROM techniques to simulate and assess structural safety requirements for a stunt training facility under dynamic loads.

*   **[Machine_Learning_for_Mechanical_Systems/Bayesian_Optimization](./Machine_Learning_for_Mechanical_Systems/)**
    *   **Focus:** Bayesian Optimization, Control Systems.
    *   **Description:** Explored advanced control strategies by tuning robot controllers using Bayesian Optimization algorithms to improve trajectory tracking and system stability.
